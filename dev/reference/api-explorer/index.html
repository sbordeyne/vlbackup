    snapshot¶

    POST /v1/vlbackup/snapshot¶

    Snapshot a range of partitions to Object Storage

    Description

    For each sealed day in the requested range, creates a VictoriaLogs snapshot of the local partition, streams it as a tar.gz to the destination Object Storage bucket, and deletes the local snapshot.

    POST /v1/vlbackup/migrate¶

    Migrate partitions and recent data to another vlbackup instance

    Description

    Like transfer, but also migrates the most recent (still-open) data. For each sealed day in the requested range it moves the partition to the target vlbackup (snapshot, stream, detach, attach). It then copies today's data by querying the local VictoriaLogs over LogsQL as streamed JSONLine and ingesting it into the target's JSON stream API. Today's data is copied (the source is left intact) and ingestion is at-least-once: a re-run re-inserts today's rows, since VictoriaLogs does not deduplicate on ingest.

    Request body

    {
    "target_vlbackup_url": "http://target-vlbackup:8080",
    "target_vlinsert_url": "http://target-vlinsert:9428",
    "target_vlselect_url": "http://target-vlselect:9428",
    "target_vl_auth_key": "string",
    "range": null
}

    Schemas¶

    AttachResponse¶

    Name Type Description
    partition string The partition that was attached, formatted as YYYYMMDD

    ErrorResponse¶

    Name Type Description
    code integer(int32) HTTP status code associated with the error
    error string Error message describing the issue

    MigrateRequest¶

    Name Type Description
    range Inclusive time range whose sealed days will be migrated
    target_vl_auth_key string Optional auth key for the target VictoriaLogs insert/select APIs, passed as the VictoriaLogs authKey
    target_vlbackup_url string(url) Base URL of the target vlbackup instance, used to move sealed partitions (receive/attach)
    target_vlinsert_url string(url) Base URL of the target VictoriaLogs insert API, used to ingest today's data via the JSON stream API
    target_vlselect_url string(url) Base URL of the target VictoriaLogs select API, used to verify ingested row counts after migration

    MigrateResponse¶

    Name Type Description
    errors Array<string> Per-day and recent-phase error messages
    recent The outcome of copying today's (still-open) data
    skipped Array<string> Sealed partitions (YYYYMMDD) that were skipped, e.g. missing or already present on the target
    transferred Array<string> Sealed partitions (YYYYMMDD) that were successfully moved

    ReceiveResponse¶

    Name Type Description
    bytes_written integer(int64) Number of bytes written to disk while extracting the snapshot
    partition string The partition that was received, formatted as YYYYMMDD

    RecentMigration¶

    Name Type Description
    bytes_ingested integer(int64) Number of JSONLine bytes streamed to the target insert API
    partition string Today's partition (YYYYMMDD) whose data was copied
    source_count integer(int64) Row count for today on the source, from the verification query
    target_count integer(int64) Row count for today on the target, from the verification query
    verified boolean True when the target row count is at least the source row count

    RestoreRequest¶

    Name Type Description
    partition_prefix string Partition to restore, formatted as YYYYMMDD
    source_url string(url) Object Storage source URL to restore from, e.g. gs://bucket/prefix/ or s3://bucket/prefix/

    RestoreResponse¶

    Name Type Description
    bytes_written integer(int64) Number of bytes written to disk while extracting the snapshot
    partition Array<string> Array of partitions restored

    SnapshotRequest¶

    Name Type Description
    destination_url string(url) Object Storage destination URL, e.g. gs://bucket/prefix/ or s3://bucket/prefix/
    range Inclusive time range whose days will be snapshotted

    TimeRange¶

    Name Type Description
    from string Start of the range, inclusive. A relative or absolute time expression (e.g. `now-7d/d`, `2024-01-01T00:00:00Z`).
    to string End of the range, inclusive. A relative or absolute time expression (e.g. `now/d`, `2024-01-15T00:00:00Z`). Defaults to now.

    TransferRequest¶

    Name Type Description
    range Inclusive time range whose days will be transferred
    target_url string(url) Base URL of the target vlbackup instance to transfer partitions to

    TransferResponse¶

    Name Type Description
    errors Array<string> Per-day error messages for partitions that failed to transfer
    skipped Array<string> Partitions (YYYYMMDD) that were skipped, e.g. missing or already present on the target
    transferred Array<string> Partitions (YYYYMMDD) that were successfully transferred
